# MYDS

The Malaysian Government Design System: the shared design language and component library that government digital services build on.

## Language

**Design Language Guideline**:
The written principles, foundations and component usage rules for designers, published at design.digital.gov.my under "Design".
_Avoid_: design docs, style guide

**Component Library**:
The reusable UI components and style tokens that implement the Design Language Guideline for developers.
_Avoid_: UI kit

**Consumer project**:
A government digital service, built by a team outside this repo, that uses MYDS.
_Avoid_: client app, downstream

**DESIGN.md**:
A single file that describes the MYDS design language to AI agents working in a Consumer project, so the UI they produce looks and behaves like MYDS.
_Avoid_: design doc, design spec
